Chenglong Wang

Associate Professor, Northeastern University (Shenyang, China)
Email Google Scholar GitHub

I received my Ph.D. from Northeastern University in 2026, advised by Prof. Tong Xiao and Prof. Jingbo Zhu. I am currently an Associate Professor in the College of Computer Science and Engineering at Northeastern University. My research lies in natural language processing, with a particular focus on large language model alignment, including reward modeling, efficient reinforcement learning, reasoning enhancement, and LLM alignment in multilingual and multimodal settings. I have served as an Area Chair for ACL 2026, EMNLP 2026, NLPCC 2026. I received the EMNLP 2024 Outstanding Reviewer Award, the CCL 2025 Highlight Poster Award, the CCMT 2025 Highlight Poster Award, and the ACL 2026 SAC Highlight Award. As a core member of the NiuTrans team, I also participated in the WMT 2021 shared tasks, where our system won the English-Russian translation task and the efficiency task.

Selected Publications

Only papers from the past five years are shown, sorted by recency. Representative papers are highlighted. A full list can be found in Google Scholar.

2026

On the Emotion Understanding of Synthesized Speech
Yuan Ge, Haishu Zhao, Aokai Hao, Junxiang Zhang, Bei Li, Xiaoqian Liu, Chenglong Wang, Jianjin Wang, Bingsen Zhou, Bingyu Liu, Jingbo Zhu, Zhengtao Yu, Tong Xiao
ACL, 2026 SAC Highlight Award
pdf /
Abstract

This work studies whether speech emotion recognition models reliably transfer to synthesized speech. It finds that current models often fail to generalize because synthesized speech can introduce representation mismatches and shortcut-based emotion cues.

SERM: Self-Evolving Relevance Model with Agent-Driven Learning from Massive Query Streams
Chenglong Wang, Canjia Li, Xingzhao Zhu, Yifu Huo, Huiyu Wang, Weixiong Lin, Yun Yang, Qiaozhi He, Tianhua Zhou, Xiaojia Chang, Jingbo Zhu, Tong Xiao
ACL Findings, 2026
pdf /
Abstract

SERM studies how relevance models can continuously adapt to massive, shifting query streams. It uses agent-driven sample mining and annotation to make self-evolution more reliable, connecting alignment-style feedback loops with large-scale multilingual search.

SPS: Steering Probability Squeezing for Better Exploration in Reinforcement Learning for Large Language Models
Yifu Huo, Chenglong Wang, Ziming Zhu, Shunjie Xing, Peinan Feng, Tongran Liu, Qiaozhi He, Tianhua Zhou, Xiaojia Chang, Jingbo Zhu, Zhengtao Yu, Tong Xiao
ACL Findings, 2026
pdf /
Abstract

SPS analyzes the probability-squeezing effect in RL for reasoning LLMs, where training over-concentrates probability mass on a narrow set of trajectories. By alternating RL with inverse RL, it improves exploration and Pass@k without requiring extra supervision.

MSRL: Scaling Generative Multimodal Reward Modeling via Multi-Stage Reinforcement Learning
Chenglong Wang, Yifu Huo, Yang Gan, Qiaozhi He, Qi Meng, Bei Li, Yan Wang, Junfu Liu, Tianhua Zhou, Jingbo Zhu, Tong Xiao
CVPR, 2026
pdf / code /
Abstract

MSRL scales generative multimodal reward modeling with limited multimodal preference data. It transfers reward reasoning from textual preferences through caption-based and multimodal RL stages, improving alignment for both visual understanding and generation.

Probing Preference Representations: A Multi-Dimensional Evaluation and Analysis Method for Reward Models
Chenglong Wang, Yifu Huo, Yang Gan, Yongyu Mu, Qiaozhi He, Murun Yang, Bei Li, Chunliang Zhang, Tongran Liu, Anxiang Ma, Zhengtao Yu, Jingbo Zhu, Tong Xiao
AAAI, 2026
pdf / code / dataset /
Abstract

This work introduces MRMBench and inference-time probing to diagnose what preference dimensions reward models actually capture. The analysis makes reward model evaluation more interpretable and more directly connected to downstream LLM alignment quality.

GRAM-R2: Self-Training Generative Foundation Reward Models for Reward Reasoning
Chenglong Wang, Yongyu Mu, Hang Zhou, Yifu Huo, Ziming Zhu, Jiali Zeng, Murun Yang, Bei Li, Tong Xiao, Xiaoyang Hao, Chunliang Zhang, Fandong Meng, Jingbo Zhu
AAAI, 2026 Oral
pdf / code / models / dataset /
Abstract

GRAM-R2 extends generative foundation reward modeling with self-training on unlabeled data. It learns to produce both preference judgments and reward rationales, strengthening reward reasoning for ranking, task adaptation, and RLHF.

2025

MRO: Enhancing Reasoning in Diffusion Language Models via Multi-Reward Optimization
Chenglong Wang, Yang Gan, Hang Zhou, Chi Hu, Yongyu Mu, Kai Song, Murun Yang, Bei Li, Chunliang Zhang, Tongran Liu, Jingbo Zhu, Zhengtao Yu, Tong Xiao
NeurIPS, 2025
pdf / code /
Abstract

MRO improves reasoning in diffusion language models by optimizing token correlations during denoising. It combines multi-reward optimization, efficient sampling, and test-time scaling, linking faster generation with stronger reasoning-oriented alignment.

LaTeXTrans: Structured LaTeX Translation with Multi-Agent Coordination
Ziming Zhu, Chenglong Wang, Shunjie Xing, Yifu Huo, Fengning Tian, Quan Du, Di Yang, Chunliang Zhang, Tong Xiao, Jingbo Zhu
arXiv, 2025
pdf / code /
Abstract

LaTeXTrans is a multi-agent document translation system that preserves equations, references, terminology, and compilability. It shows how agent coordination can make specialized NLP workflows more reliable beyond plain-text translation.

Step-level Verifier-guided Hybrid Test-Time Scaling for Large Language Models
Kaiyan Chang, Yonghao Shi, Chenglong Wang, Hang Zhou, Chi Hu, Xiaoqian Liu, Yingfeng Luo, Yuan Ge, Tong Xiao, Jingbo Zhu
EMNLP, 2025
pdf / code /
Abstract

This paper enhances reasoning at inference time with process-verifier-guided self-refinement and step-level hybrid test-time scaling. The training-free design complements RL-based alignment by expanding reasoning performance without additional model training.

HEAL: A Hypothesis-Based Preference-Aware Analysis Framework
Yifu Huo, Chenglong Wang, Qiren Zhu, Shunjie Xing, Tong Xiao, Chunliang Zhang, Tongran Liu, Jinbo Zhu
EMNLP Findings, 2025
pdf / code /
Abstract

HEAL evaluates preference optimization across a hypothesis space instead of a single sampled response. It provides diagnostic metrics for ranking consistency and preference strength, helping analyze what LLM alignment methods really learn.

GRAM: A Generative Foundation Reward Model for Reward Generalization
Chenglong Wang, Yang Gan, Yifu Huo, Yongyu Mu, Qiaozhi He, Murun Yang, Bei Li, Tong Xiao, Chunliang Zhang, Tongran Liu, Jingbo Zhu
ICML, 2025 CCMT 2025 Highlight Poster
pdf / code / models / dataset /
Abstract

GRAM trains a generative foundation reward model with both unlabeled and labeled data. By connecting generative modeling and pairwise preference objectives, it improves reward generalization for ranking, RLHF, and task adaptation.

RoVRM: A Robust Visual Reward Model Optimized via Auxiliary Textual Preference Data
Chenglong Wang, Yang Gan, Yifu Huo, Yongyu Mu, Murun Yang, Qiaozhi He, Tong Xiao, Chunliang Zhang, Tongran Liu, Quan Du, Di Yang, Jingbo Zhu
AAAI, 2025
pdf / code / models /
Abstract

RoVRM tackles the scarcity of visual preference data by transferring useful signals from auxiliary textual preferences. The resulting visual reward model improves LVLM alignment and reduces hallucination-related preference failures.

Learning Evaluation Models from Large Language Models for Sequence Generation
Chenglong Wang, Hang Zhou, Kaiyan Chang, Tongran Liu, Chunliang Zhang, Quan Du, Tong Xiao, Jingbo Zhu
TASLP, 2025
pdf / code /
Abstract

This work uses LLMs to synthesize labeled evaluation data for customizable sequence evaluation models. The learned metrics can support reranking and RL-style optimization without relying on costly human evaluation labels.

PCRM introduces prior constraints, such as length ratio and semantic similarity, into reward model training. These constraints stabilize reward score scaling and improve downstream alignment under RLHF- and DPO-style optimization.

Hybrid Alignment Training alternates instruction-following and preference-alignment objectives instead of treating them as isolated stages. The method helps LLMs preserve both instruction adherence and human-preference alignment.
